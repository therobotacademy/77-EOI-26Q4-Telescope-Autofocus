# Defocused-star dataset v1 (physical simulator)

20,000 synthetic 64×64 star cut-outs in raw ADU, each labelled with the **signed focus error dz**
(µm at the focal plane; dz < 0 = inside focus, dz > 0 = outside focus). Generated by `star_sim.py`
with Fourier optics, calibrated against one real frame (screenshot, 2026-11-18).

**Status: first version with TYPICAL telescope values.** The optics (200 mm f/5, 30% obstruction,
3.76 µm pixels, 0.4 waves of spherical aberration) are assumptions until the real telescope and camera
are known. The sign cue comes from the spherical aberration; its true size must be measured on a real
focuser sweep before trusting sign accuracy on real stars.

## How each image is made

1. Pupil: 200 mm aperture with a 30% central obstruction (no spider vanes by default).
2. Phase: defocus W (P-V waves, uniform in ±11, so dz = 110 µm × W, ±1,210 µm) + fixed spherical
   aberration 0.4 waves + random astigmatism and coma (0.15 waves RMS each) + a Kolmogorov
   turbulence screen (D/r0 from 2 to 5).
3. Star image = |FFT(pupil)|², integrated into 64×64 camera pixels (1.37 λ/D per pixel).
4. Seeing blur: Moffat profile, FWHM 6–12 px, β 2.5–4.5. Centre shifted by up to ±3 px.
5. Sensor: sky 50–800 e⁻/px, flux chosen so the donut is 3–12× the background noise,
   Poisson + read noise (3–10 e⁻), gain 1 e⁻/ADU, bias 100 ADU, rounded, clipped at 65,535.

## File `defocus_stars_v1.npz`

| Key | Shape, type | Meaning |
|---|---|---|
| `adu` | (20000, 64, 64), uint16 | Raw image in ADU (includes 100 ADU bias) |
| `dz_um` | (20000,), float32 | **Label**: signed focus error, µm at the focal plane |
| `defocus_waves` | (20000,) | Same label in waves of P-V defocus (dz = 110 µm × waves) |
| `seeing_fwhm_px`, `moffat_beta`, `d_over_r0` | (20000,) | Atmosphere settings per image |
| `astig0_waves`, `astig45_waves`, `comax_waves`, `comay_waves` | (20000,) | Random aberrations |
| `shift_x_px`, `shift_y_px` | (20000,) | Star offset from the cut-out centre |
| `sky_e`, `read_noise_e`, `ring_snr`, `flux_e` | (20000,) | Sensor and signal settings |
| `train_idx`, `val_idx`, `test_idx` | 16,000 / 2,000 / 2,000 | Index splits |
| `config` | JSON string | Full telescope and range settings, seeds |

```python
import numpy as np
z = np.load("defocus_stars_v1.npz")
X, dz = z["adu"].astype(np.float32), z["dz_um"]
X_train, dz_train = X[z["train_idx"]], dz[z["train_idx"]]
```

## Rebuild or change

```
python make_dataset_v1.py 20000 defocus_stars_v1.npz   # ~7 min on 2 CPU cores; needs numpy, torch
```
Edit `Telescope` and `Ranges` at the top of `star_sim.py` for the real optics and camera.
`preprocess()` in `star_sim.py` is a placeholder: replace it with the real "preprocesada" step and
apply it identically to synthetic and real images.

## HFR baseline (blur size only)

`python hfr_baseline.py defocus_stars_v1.npz` (numpy only). It measures the half-flux radius of each
star, then maps it to |dz| with a monotone curve fitted on the train split. Centroid threshold (2σ) and
aperture (38 px radius) were chosen on the val split. HFR gives no sign.

Test split (2,000 images): **MAE of |dz| 64.9 µm** (median error 54 µm; a constant guess gives 302 µm).
Depth of focus (DoF) here means the quarter-wave tolerance ±2λN² = ±27.5 µm.

| \|dz\| bin (µm) | n | MAE (µm) | MAE (DoF) | Bias (µm) |
|---|---|---|---|---|
| 0–200 | 357 | 84 | 3.0 | +72 |
| 200–400 | 308 | 77 | 2.8 | −25 |
| 400–800 | 664 | 65 | 2.3 | −10 |
| 800–1200 | 657 | 49 | 1.8 | −8 |
| 1200–1600 | 14 | 75 | 2.7 | −75 |

The 148 µm of `train_check_v1.py` is a **signed** error, so it is not comparable with these numbers.
On the same test split, the 4-block CNN trained on |dz| for 40 epochs reaches **46.6 µm** (mean of 3 seeds),
see [report 05](../REPORTS/05-cnn-blur-size.md): `python cnn_vs_hfr.py defocus_stars_v1.npz 40 3` (torch).

## Known limits

- Calibrated on ONE real frame, seen through a screenshot (grey levels, not true ADU).
- Single wavelength (0.55 µm); no colour smearing. No hot pixels, cosmic rays, sky gradients or
  neighbouring stars. Flux never saturates.
- The intra/extra difference depends on the assumed spherical aberration (0.4 waves).
